# ISO 9001 Auditor Fragen – Checkliste

Statische, SEO-optimierte Landingpage (Single-File HTML) für die Subdomain **audit-checkliste.qm-guru.de**.

## Lokal öffnen
- Datei direkt öffnen: `index.html` (Doppelklick) oder
- besser mit einem kleinen Server (für korrektes Verhalten in allen Browsern):
  - VS Code Extension: "Live Server" oder
  - Python: `python -m http.server 8080`

## Netlify
- Publish directory: `.`
- Build command: leer

## Deploy zu GitHub (VS Code)
1. VS Code → Ordner öffnen
2. Terminal:
   - `git init`
   - `git add .`
   - `git commit -m "Initial: ISO 9001 Auditor Fragen Checkliste"`
3. Source Control → "Publish to GitHub" (oder Remote setzen und pushen)
